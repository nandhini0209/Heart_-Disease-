What Is Heart Risk AI?

Heart Risk AI is a machine learning web application that predicts the likelihood of heart disease based on 13 clinical features from the UCI Heart Disease Dataset. It is designed for educational and portfolio purposes.

How It Works
  • A Random Forest Classifier is trained on the UCI Heart Disease dataset.
  • The model uses 13 clinical features such as age, cholesterol, and heart rate.
  • Input data is scaled using StandardScaler before prediction for accuracy.
  • The result shows a risk probability percentage and a high/low risk verdict.
Dataset

The dataset used is the UCI Heart Disease Dataset (Cleveland Clinic Foundation). It contains 303 patient records with 13 features and a binary target (0 = No Disease, 1 = Disease).

Tech Stack
  • Backend: Python, Flask
  • Machine Learning: Scikit-learn (Random Forest Classifier)
  • Frontend: HTML, CSS, Bootstrap 5, JavaScript
  • Model Persistence: Python Pickle
  • Deployment: Render.com
